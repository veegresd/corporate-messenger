# Corporate Messenger

Учебный проект корпоративного мессенджера.

## Цель проекта

Разработка корпоративного мессенджера с поддержкой:

* личных сообщений;
* групповых чатов;
* ролей пользователей;
* администрирования;
* дальнейшего расширения под звонки и мобильные приложения.

## Технологии

### Backend

* Node.js
* Express

### Планируется

* PostgreSQL
* JWT
* Socket.IO
* React

## Статус

Находится в активной разработке.
